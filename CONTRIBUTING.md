# 🤝 Como Contribuir

Contribuições são bem-vindas! Este é um projeto educacional e qualquer melhoria que ajude gestores municipais a entenderem melhor a LGPD é válida.

---

## O que você pode contribuir

- **Correções** — erros em referências legais, artigos ou descrições
- **Novas perguntas** — sugestões de perguntas mais precisas para o diagnóstico
- **Documentação** — melhorias no README, FAQ ou referências
- **Adaptações regionais** — instruções de outros Tribunais de Contas estaduais
- **Acessibilidade** — melhorias de usabilidade e acessibilidade da interface

---

## Como abrir uma contribuição

1. Faça um fork do repositório
2. Crie uma branch descritiva: `git checkout -b melhoria/nome-da-melhoria`
3. Faça suas alterações
4. Abra um Pull Request com descrição clara do que foi alterado e por quê

---

## Abrindo Issues

Se encontrou um erro ou tem uma sugestão mas não quer implementar, abra uma [issue](https://github.com/gilbertocrv/lgpd-municipal/issues) descrevendo:

- O problema ou sugestão
- A referência legal relevante (se aplicável)
- O comportamento esperado

---

## Código de Conduta

Este projeto é técnico e educacional. Mantenha as discussões respeitosas e baseadas em fatos e referências legais verificáveis.
